## Read this before you trust a detail

- These notes were written while I was learning, so they can be wrong in places. Where they disagree with the handbook or the Google Cloud docs, trust the docs.
- Google renamed several products while I was learning. Early notes use the old names, such as Dataproc, Cloud Composer, Dataplex, BigLake, Looker Studio and Vertex AI. The table at the top of the first file lists the new names.
- Console screens change often. Treat the hands-on write-ups as a guide to what I learned, not as current click-by-click steps.
